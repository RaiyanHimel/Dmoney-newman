# Dmoney User Management

## Overview

Dmoney is a fake money transaction portal where users can send money, deposit, cash out, and make payments to other users.

## Technology Stack

- **NodeJS** - Runtime environment
- **Postman** - API testing
- **Newman** - Postman CLI
- **HTML Report Extra** - Report generation

## Getting Started

### Prerequisites

- Node.js installed
- Secret key required to run this project

### Installation & Usage

```bash
npm install
npm test
```
